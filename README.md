# PitchBuilder

투자유치 IR을 단계별로 작성하고, **TIPS 선정평가 기준**으로 진단받는 도구입니다.
충북대학교기술지주㈜ · 2026 이노테크 창업 지원.

- **의존성 0 · 단일 HTML** — 외부 스크립트를 부르지 않습니다.
- 접속에는 배부받은 **접수번호와 접속코드**가 필요합니다.
- 진단은 참고용입니다. 배점은 공식이지만 **등급 판정 기준선은 이 도구의 자체 정의**입니다.

## 알아두실 것

TIPS 100점 중 40점(개발 적정성·실현성·글로벌·운영사)은 IR이 아니라
**R&D 사업계획서**에서 평가합니다. IR만으로는 60점 컷에 닿지 않는 것이 정상이며,
**TIPS 준비 모드**를 켜면 채점 범위가 90점까지 넓어집니다.
